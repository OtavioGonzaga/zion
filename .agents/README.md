# Agent Workspace

This directory contains repository-specific material for coding agents.

| Directory    | Purpose                    | Versioned |
| ------------ | -------------------------- | --------- |
| `memory/`    | Durable project knowledge  | Yes       |
| `prompts/`   | Reusable prompts           | Yes       |
| `skills/`    | Reusable agent skills      | Yes       |
| `artifacts/` | Temporary working material | No        |

Keep temporary plans, reports, and source artifacts under `artifacts/`. Promote
only reusable knowledge or guidance into a versioned directory.
